## Backend Frameworks with Frontend

| **Backend Framework**        | **Language** | **Frontend Built-in** | **Best Frontend Pairings** | **Common Use Cases**     |
| ---------------------------- | ------------ | --------------------- | -------------------------- | ------------------------ |
| Node.js + Express            | JavaScript   | No                    | React, Vue, Next.js        | Web APIs, SaaS, Realtime |
| Django + DRF                 | Python       | Yes (templates)       | React, Vue, HTMX           | Web apps, ML dashboards  |
| Spring Boot                  | Java         | Yes (Thymeleaf)       | Angular, React             | Enterprise, banking      |
| FastAPI                      | Python       | No                    | React, Svelte, SolidJS     | APIs, ML, startups       |
| Laravel                      | PHP          | Yes (Blade, Inertia)  | Vue, React, Livewire       | SaaS, CMS, e-commerce    |
| .NET (WebAPI)                | C#           | No                    | React, Angular, Blazor     | Corporate, enterprise    |
| NestJS                       | TypeScript   | No                    | Angular, React             | Modular apps, GraphQL    |
| Ruby on Rails                | Ruby         | Yes (ERB, Turbo)      | Hotwire, React             | MVPs, startups           |
| Flask                        | Python       | Yes (Jinja2)          | Vue, React, jQuery         | Lightweight apps, APIs   |
| Phoenix                      | Elixir       | Yes (LiveView)        | LiveView, React            | Realtime, chat, scale    |
| Go + Gin                     | Go           | No                    | React, Svelte, Vue         | Fast APIs, microservices |
| .NET (MVC)                   | C#           | Yes (Razor)           | Vanilla JS, Blazor         | Enterprise apps          |
| Blazor (WASM)                | C#           | Yes (SPA in C#)       | N/A (built-in)             | SPAs, .NET frontends     |
| Koa.js                       | JavaScript   | No                    | React, Vue                 | Lightweight APIs         |
| Hapi.js                      | JavaScript   | No                    | React, Vue                 | Secure, complex APIs     |
| Rocket                       | Rust         | Yes (Templates)       | Yew (Rust), React          | Safe APIs, high perf     |
| Actix Web                    | Rust         | No                    | React, Svelte              | Hardcore perf backends   |
| Micronaut                    | Java         | Yes (via Views)       | Angular, React             | Microservices            |
| AdonisJS                     | JS/TS        | Yes (Edge templates)  | React, Vue                 | Laravel-style in JS      |
| Strapi (Headless CMS)        | JavaScript   | No (Admin UI)         | Next.js, Nuxt, Gatsby      | CMS, content APIs        |
| KeystoneJS                   | JavaScript   | No                    | React                      | Headless CMS & Admin UI  |
| Sails.js                     | JavaScript   | Yes (Views optional)  | Angular, React             | MVC in Node              |
| LoopBack                     | JS/TS        | No                    | Any                        | API creation, modeling   |
| FeathersJS                   | JavaScript   | No                    | React, Angular             | Realtime APIs            |
| Tornado                      | Python       | Yes (basic templates) | React, Vue                 | Async Python services    |
| Symfony                      | PHP          | Yes (Twig templates)  | Vue, React                 | Enterprise PHP stack     |
| CodeIgniter                  | PHP          | Yes                   | Vanilla JS, Vue            | Lightweight PHP apps     |
| Bottle                       | Python       | Yes (basic)           | jQuery, Pure JS            | Microservices, IoT       |
| Moleculer                    | JavaScript   | No                    | Any SPA                    | Microservices, eventing  |
| Serverless (Lambda, Netlify) | Any          | No                    | React, Vue, Astro          | Event-driven APIs        |
