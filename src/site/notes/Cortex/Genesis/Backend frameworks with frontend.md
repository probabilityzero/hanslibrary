## Backend Frameworks with Frontend

| **Backend Framework**        | **Lang** | **Frontend Built-in** | **Best Frontend Pairings** | **Common Use Cases**     |
| ---------------------------- | -------- | --------------------- | -------------------------- | ------------------------ |
| Node.js + Express            | JS       | No                    | React, Vue, Next.js        | Web APIs, SaaS, Realtime |
| Django + DRF                 | Python   | (templates)       | React, Vue, HTMX           | Web apps, ML dashboards  |
| Spring Boot                  | Java     | (Thymeleaf)       | Angular, React             | Enterprise, banking      |
| FastAPI                      | Python   | No                    | React, Svelte, SolidJS     | APIs, ML, startups       |
| Laravel                      | PHP      | (Blade, Inertia)  | Vue, React, Livewire       | SaaS, CMS, e-commerce    |
| .NET (WebAPI)                | C#       | No                    | React, Angular, Blazor     | Corporate, enterprise    |
| NestJS                       | TS       | No                    | Angular, React             | Modular apps, GraphQL    |
| Ruby on Rails                | Ruby     | (ERB, Turbo)      | Hotwire, React             | MVPs, startups           |
| Flask                        | Python   | (Jinja2)          | Vue, React, jQuery         | Lightweight apps, APIs   |
| Phoenix                      | Elixir   | (LiveView)        | LiveView, React            | Realtime, chat, scale    |
| Go + Gin                     | Go       | No                    | React, Svelte, Vue         | Fast APIs, microservices |
| .NET (MVC)                   | C#       | (Razor)           | Vanilla JS, Blazor         | Enterprise apps          |
| Blazor (WASM)                | C#       | (SPA in C#)       | N/A (built-in)             | SPAs, .NET frontends     |
| Koa.js                       | JS       | No                    | React, Vue                 | Lightweight APIs         |
| Hapi.js                      | JS       | No                    | React, Vue                 | Secure, complex APIs     |
| Rocket                       | Rust     | (Templates)       | Yew (Rust), React          | Safe APIs, high perf     |
| Actix Web                    | Rust     | No                    | React, Svelte              | Hardcore perf backends   |
| Micronaut                    | Java     | (via Views)       | Angular, React             | Microservices            |
| AdonisJS                     | JS/TS    | (Edge templates)  | React, Vue                 | Laravel-style in JS      |
| Strapi                       | JS       | No (Admin UI)         | Next.js, Nuxt, Gatsby      | CMS, content APIs        |
| KeystoneJS                   | JS       | No                    | React                      | Headless CMS & Admin UI  |
| Sails.js                     | JS       | (Views optional)  | Angular, React             | MVC in Node              |
| LoopBack                     | JS/TS    | No                    | Any                        | API creation, modeling   |
| FeathersJS                   | JS       | No                    | React, Angular             | Realtime APIs            |
| Tornado                      | Python   | (basic templates) | React, Vue                 | Async Python services    |
| Symfony                      | PHP      | (Twig templates)  | Vue, React                 | Enterprise PHP stack     |
| CodeIgniter                  | PHP      | Yes                   | Vanilla JS, Vue            | Lightweight PHP apps     |
| Bottle                       | Python   | (basic)           | jQuery, Pure JS            | Microservices, IoT       |
| Moleculer                    | JS       | No                    | Any SPA                    | Microservices, eventing  |
| Serverless (Lambda, Netlify) | Any      | No                    | React, Vue, Astro          | Event-driven APIs        |
