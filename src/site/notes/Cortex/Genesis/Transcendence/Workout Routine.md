## **Weekly workout routine (with equipment)**

|**Day**|**Focus**|**Structure**|
|---|---|---|
|**Mon**|Upper (Heavy)|Push + Pull + optional core finisher|
|**Tue**|Lower + Core|Legs + Core|
|**Wed**|Core + Upper (Extra)|Core block first, lighter upper volume|
|**Thu**|Lower + Core|Legs + Core|
|**Fri**|Upper (Heavy)|Push + Pull + optional core finisher|
|**Sat**|Core + Upper (Extra)|Core block first, lighter upper volume|
|**Sun**|Active Recovery Lower|Walking, mobility, calves, banded activation|

---

### **Monday (Upper Heavy)**

- _Incline Push-Ups (feet elevated)_: 3×10–15
- _Dumbbell Bench Press_: 3×8–12
- _Dumbbell Shoulder Press_: 3×8–12
- _Pull-Ups / Assisted Pull-Ups_: 3×6–10
- _One-Arm Dumbbell Row_: 3×8–12/side
- _Face Pulls (band)_: 3×12–15
- Optional Plank 2×60 sec

---

### **Tuesday (Lower + Core)**

- Goblet Squat (DB): 4×12–15
- Romanian Deadlift (DB): 3×10–15
- Bulgarian Split Squat: 3×8–12/leg
- Calf Raises (weighted): 4×15–20
- Ab Wheel Rollouts (if available): 3×8–12
- Hanging Knee Raises: 3×10–15

---

### **Wednesday (Core + Upper Extra)**

- Core Block:
    - Weighted Plank 2×45 sec
    - Leg Raises 3×12
    - Side Plank 2×40 sec/side
- Upper Extra:
    - Dumbbell Flyes: 3×10–15
    - Band Pull-Aparts: 3×15–20
    - Pike Push-Ups: 2×10–12

---

### **Thursday (Lower + Core)**

- Sumo Deadlift (DB): 4×8–12
- Step-Ups (DB): 3×10/leg
- Hip Thrust (DB on hips): 3×12–15
- Standing Calf Raises: 4×15–20
- Core Block: Bicycle Crunch 3×20, Reverse Crunch 3×15

---

### **Friday (Upper Heavy)**

- Push-Ups (weighted backpack): 3×15–20
- Dumbbell Overhead Press: 3×8–12
- Chin-Ups: 3×6–10
- Bent Over Rows (DB): 3×8–12
- Band Face Pulls: 3×15
- Optional Plank Variations 2×60 sec

---

### **Saturday (Core + Upper Extra)**

- Core Block:
    - Cable/Band Pallof Press: 3×12/side
    - V-Ups: 3×12
    - Side Plank Reach-Through: 2×12/side
- Upper Extra:
    - Band/Cable Lateral Raises: 3×12–15
    - Diamond Push-Ups: 2×10–12
    - Resistance Band Curls: 3×12–15

---

### **Sunday (Active Recovery Lower)**

- 30–60 min sports and playground 
- Bodyweight Lunges 2×20
- Ankle, hip, and calf mobility drills
- Banded Glute Activation (clamshells, abductions) 2×20

---

✅ **Add 2.5–5 kg when rep range is consistently met** while maintaining form.  
✅ **Tempo manipulation** (3s eccentric) if unable to increase weight.  
✅ **Track weights and reps** for each session for visible progression.
